# FAQ-бот на 5 вопросов

Бот отвечает на 5 заранее известных вопросов про репетицию хакатона (время, команда, трек, сдача, призы). Совпадение — по ключевым словам (коэффициент Жаккара), без RAG и внешних API. Два интерфейса на одном ядре: терминал и веб-чат.

## Архитектура

```
faq.txt          — база из 5 пар Q/A (единственный источник данных)
faq_engine.py    — ядро: load_faq / tokenize / find_answer (без UI-зависимостей)
main.py          — CLI-интерфейс поверх ядра
app.py           — Flask-сервер: отдаёт веб-чат и JSON API /api/ask
templates/       — HTML чата (Jinja2)
static/          — style.css (визуал) и app.js (логика чата, fetch к API)
```

Ядро (`faq_engine.py`) не знает про интерфейсы — CLI и веб просто вызывают `find_answer()`. Если понадобится Telegram-бот или что-то ещё, добавляется новый тонкий адаптер без изменения логики матчинга.

## Как запустить

### CLI (без зависимостей)

```
python main.py
```

Вопрос → ответ в терминале. Выход: `выход`, `exit` или Ctrl+C.

### Веб-чат

```
pip install -r requirements.txt
python app.py
```

Открыть `http://127.0.0.1:5000`. Интерфейс — чат с бабблами, индикатором «печатает…» и чипами-подсказками с готовыми вопросами (можно кликнуть вместо ввода). Тёмная тема по умолчанию, авто-переключение на светлую по системным настройкам, адаптив под мобильные экраны.

## Что получилось

- `faq.txt` — 5 пар `Q:`/`A:`, разделённые пустой строкой.
- Матчинг: вопрос пользователя и каждый вопрос из faq.txt токенизируются по словам, считается пересечение/объединение множеств слов. Порог совпадения — 0.2, ниже — «не знаю».
- Пример (CLI):
  ```
  > во сколько начало?
  Репетиция пройдёт в понедельник, 21 сентября, с 18:30 до 19:30.
  > какая погода завтра?
  не знаю
  ```
- Веб-версия использует тот же движок через `POST /api/ask {"question": "..."}` → `{"answer": "...", "matched": true|false}`.
